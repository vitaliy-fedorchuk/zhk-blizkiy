# ЖК «Близкий» — лендинг

Vite + чистий HTML/CSS/JS, плавний скрол — [Lenis](https://github.com/darkroomengineering/lenis), шрифти Unbounded і Montserrat підключені локально через Fontsource.

## Команди

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # статична збірка в dist/ (відносні шляхи, можна класти в будь-яку папку)
npm run preview   # перегляд зібраного dist/
```

## Масштабування

Усі розміри в `rem`, змінюється лише `font-size` у `html` ([base.css](src/styles/base.css)):

- ≥1200px — `clamp(16px, 17px + (100vw - 1440px) / 480, 19px)`: +6% на 1440px, +12% на 1920px, максимум +18%; контент обмежений контейнером;
- 768–1199px — 16px, звичайний адаптив;
- <768px — `min(100vw / 390 * 16, 18px)`: мобільний макет 390px масштабується за шириною екрана.

Щоб зробити сайт більшим чи меншим, змініть лише ці значення.

## Що треба доналаштувати

- **Форма.** У `index.html` у `<form data-endpoint="">` вкажіть URL обробника форм поточного сайту (POST, FormData: `name`, `phone`, `consent`). Поки endpoint порожній, форма працює в демо-режимі.
- **Карта.** Зараз iframe-віджет Яндекса з пошуком адреси (`data-map-src` у блоці `.map`). Щоб показати мітки об'єктів, створіть карту в Конструкторі Яндекс Карт і підставте її посилання або скрипт.
- **Посилання-заглушка** `href="#"`: сайт забудовника РСК.
- **Попапи.** `request` відкривається з усіх кнопок `data-modal-open="request"`, `promo` — сам через 10 с (раз за сесію, не після відправленої заявки). Затримка — `PROMO_DELAY` у [modals.js](src/js/modals.js).
- **Метрика.** Після успішної відправки викликається `ym(112185762, 'reachGoal', 'form_submit')`, якщо лічильник Яндекс Метрики підключено на сторінці.
- **Політика.** Текст перенесено дослівно з поточного сайту; в оригіналі порожні адреса Оператора («по адресу:(далее…») і поштова адреса для відкликання («по адресу .») — потрібні дані від клієнта.
- **Планування.** У макеті 8 карток; «Показать еще» показує наступну порцію (4 на мобільному, 8 на десктопі) і ховається, коли все показано. Решту 30 планувань додайте тими ж `<article class="plan-card">`.
